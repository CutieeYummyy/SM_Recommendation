# DEMO 
## Key Features:
- Create supermarket map: The program automatically creates supermarket maps for fields and products.
- Product suggestion:
  - Suggest products based on product name (using TF-IDF and Cosine Similarity).
  - Suggest products for users based on shopping history (using Collaborative Filtering with SVD algorithm).
- Find optimal path: Use Genetic Algorithm (GA) algorithm to find the shortest linear path for users from point to point in the supermarket.
